# Onboarding Guide

Follow these quick steps to start using HemoAI effectively:

1. Choose your preferred language.
2. Enter basic profile information (age, gender if desired, baseline health goals).
3. Add your first hemogram test values.
4. Set reminders for future tests and medications.
5. Enable backup (local or cloud) to safeguard your data.
6. Explore the dashboard and AI analysis sections for insights.
7. Consider Premium for advanced analytics and priority support.

Tips
- Add at least two tests over time to see trend insights.
- Use family panel to monitor relatives responsibly.
- Export JSON/PDF for sharing with healthcare professionals.
