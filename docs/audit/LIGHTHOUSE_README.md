# Lighthouse Reports

Store exported Lighthouse reports (HTML and JSON) here.

Suggested naming:
- YYYY-MM-DD-lighthouse-desktop.html
- YYYY-MM-DD-lighthouse-desktop.json
- YYYY-MM-DD-lighthouse-mobile.html
- YYYY-MM-DD-lighthouse-mobile.json

When filing results, add a brief summary of scores and action items to docs/performance/README.md or a new markdown in this folder.
