## 📝 Formspree Kurulum Adımları

1. **Formspree hesabı oluştur:** https://formspree.io/accounts/signup
2. **Yeni form oluştur:**
   - Form name: "HemoAI Support"
   - Email: support@hemoai.com
   - Form ID alın: `xxxxxxxxxxxx` (form ID)
3. **Form ID'yi HTML'e ekleyin:**
   ```html
   <form action="https://formspree.io/f/xxxxxxxxxxxx" method="POST">
   ```

**Not:** Formspree ücretsiz planında ayda 50 form gönderimi limiti var. Daha fazlası için ücretli plan gerekebilir.

## 🚀 Deployment Adımları

1. **GitHub Repository oluştur:**
   ```bash
   # GitHub'da yeni repository oluştur
   Repository name: hemoai-support
   Description: HemoAI Support Page
   Public: ✅ (GitHub Pages için gerekli)
   ```

2. **Dosyayı yükle:**
   - `index.html` dosyasını repository'ye yükleyin
   - `README.md` ekleyin (opsiyonel)

3. **GitHub Pages'i etkinleştir:**
   - Repository → Settings → Pages
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save

4. **URL'i test edin:**
   - https://meloshemo.github.io/hemoai-support
